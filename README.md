# طرنيب أونلاين — نسخة تطوير 1.1

هذا المشروع أصبح يتكون من:
- `flutter_app/`: تطبيق Android المبني بـ Flutter.
- `backend/`: خادم Node.js + Socket.IO المسؤول عن الغرف، توزيع الورق، الطلب، الأكلات، الوقت والنتيجة.
- `web/`: نموذج الويب القديم المرفق مع النسخة الأصلية؛ بناء APK الحالي يعتمد على `flutter_app` وليس `web`.

## الميزات المنفذة في هذه النسخة

1. إنشاء غرفة خاصة برقم تلقائي ومشاركة الرقم مع الأصدقاء.
2. الانضمام إلى غرفة برقمها وكتابة اسم اللاعب.
3. اختيار نهاية المباراة: 41 أو 61.
4. أربع مقاعد، فريقان متقابلان، و13 ورقة لكل لاعب.
5. خلط وتوزيع الورق من الخادم، وليس من جهاز اللاعب.
6. مرحلة طلب من 7 إلى 13 مع اختيار نوع الطرنيب.
7. الالتزام بنوع الورقة إذا كان اللاعب يملك منها.
8. حسم الأكلة حسب أعلى طرنيب، وإلا أعلى ورقة من النوع المفتتح.
9. احتساب النقاط حتى 41 أو 61.
10. مهلة 15 ثانية لكل قرار. عند انتهاء الوقت يمرر الخادم في الطلب أو يلعب ورقة قانونية تلقائياً.
11. ستة تفاعلات سريعة متحركة: 😂 😎 😡 👏 🤔 🔥
12. عرض أوراق اللاعب في صفين، من دون سحب أفقي.
13. إعادة الاتصال واستعادة المقعد باستخدام رمز اللاعب المحفوظ، مع إمكانية المطابقة بالاسم إذا كان المقعد غير متصل.
14. بعد نهاية المباراة يمكن للاعبين التصويت للعب مرة أخرى بنفس رقم الطاولة.

## مهم قبل اللعب أونلاين

التطبيق لا يستطيع الاتصال بالإنترنت لمجرد إنشاء APK؛ يجب تشغيل خادم `backend` على عنوان عام يدعم WebSocket.

### نشر الخادم

انشر مجلد `backend` على خدمة استضافة Node.js تدعم WebSocket:
- Build command: `npm install`
- Start command: `npm start`
- المنفذ: يقرأ الخادم `process.env.PORT` تلقائياً.

بعد النشر ستحصل على رابط HTTPS مثل:
`https://your-tarneeb-server.example.com`

افتح التطبيق، اضغط ⚙️، ثم ضع رابط الخادم واحفظه. يجب أن يستخدم جميع الأصدقاء الرابط نفسه.

### تشغيل الخادم محلياً للاختبار

من داخل مجلد `backend`:
```bash
npm install
npm start
```
سيعمل على المنفذ 3000. لا تستخدم `localhost` من هاتف صديق؛ الهاتف يحتاج عنواناً يمكن الوصول إليه من الإنترنت أو شبكة الاختبار.

## بناء APK من GitHub Actions

ارفع محتويات المشروع إلى GitHub. ثم افتح:
`Actions` → `Build Tarneeb Android APK`

بعد نجاح التشغيل، حمّل الـ Artifact باسم:
`Tarneeb-Online-Release-APK`

استخرج ملف APK من ZIP وثبّته على Android. أدخل رابط الخادم من إعدادات التطبيق قبل إنشاء/دخول غرفة.

## حدود النسخة الحالية التي يجب معرفتها

- بيانات الغرف والجولات محفوظة في ذاكرة عملية Node.js. إعادة تشغيل الخادم أو نومه/إيقافه قد يؤدي إلى فقد الغرف والجولات المفتوحة. الاستعادة برقم الطاولة تعمل ما دام الخادم يحتفظ بالغرفة.
- لا يوجد حتى الآن تسجيل حسابات أو قاعدة بيانات دائمة أو سجل مباريات أو دردشة نصية.
- المطابقة بالاسم عند فقد رمز الاستعادة مخصصة لغرف الأصدقاء، وليست بديلاً آمناً عن حساب موثق. احتفظ برمز الاستعادة المخزن على جهازك.
- مهلة 15 ثانية مطبقة من جهة الخادم، ولذلك لا يستطيع اللاعب تمديدها بتغيير ساعة هاتفه.
- هذه نسخة أولية قابلة للتجربة وليست بعدُ بنية إنتاجية عالية التوفر. قبل النشر العام نوصي بإضافة قاعدة بيانات دائمة، حماية من التخمين والإساءة، ومراقبة للخادم.

## قواعد الجولة

هذه النسخة تطبق نمط طرنيب شائع: أعلى طلب يحدد نوع الطرنيب، يجب اتباع النوع المفتتح إن توفر، والطرنيب الأعلى يفوز بالأكلة وإلا تفوز أعلى ورقة من النوع المفتتح. الفريق الطالب إذا حقق طلبه يأخذ عدد أكلاته، وإذا أخفق تخصم قيمة الطلب منه، والفريق الآخر يأخذ أكلاته. قد تختلف بعض تفاصيل التسجيل بين المناطق والمجموعات؛ راجعوا قواعدكم المحلية قبل اعتماد اللعبة نهائياً.
